## 2. 身体路径与新增观测

SummonService先创建身体，再读取同UUID原版玩家存档，选择位置并注册玩家，
随后设置SURVIVAL/无敌。重进保留存档位置并检查安全落点；显式召唤读取旧身体数据，
但使用新召唤位置。没有自动恢复满血的代码，低血量可来自加载后的状态。
PathTask同层移动使用0.45格/tick的teleportTo插值，其他节点直接落位；
它不调用setHealth，也没有独立伤因记录。现有无敌标记不作为任意伤害/模组绝对免疫的证明。

新增 `HealthObservation` 和CompanionPlayer接线，日志前缀为 `[body-health]`：

- `CREATED`：构造完成后的身体。
- `LOADED` / `NO_SAVED_DATA`：实际load返回后，或没有可加载玩家数据。
- `POSITIONED`、`JOINED`、`READY`：选定位置、注册玩家、模式/无敌及落点设置完成。
- `BEFORE_TICK`、`AFTER_TICK`、`STATUS`：相邻采样之间hp/max_hp/absorption/invulnerable变化才输出。
- `BEFORE_DAMAGE` / `AFTER_DAMAGE`：调用原版hurtServer前后采样；每个身体首次伤害请求即使拒绝也记录，
  后续稳定无变化的请求不重复输出，变化仍记录。只调用原版方法一次，原返回值/异常继续传播。

每条JSON有 `body_id`、`companion_uuid`、`companion`、phase、health_changed、
previous/current（hp、max_hp、absorption、invulnerable、on_ground、fall_distance、
精确x/y/z、dimension、game_tick）；首次没有previous时为null。
普通采样即使不输出也更新previous，因此它不是上一条日志的快照。
body_id只标识本次身体对象，重进/重召会改变；不是世界存档ID，也不是桥session_id。
同名同伴的离线UUID可相同，不能只用名字/UUID判定两个存档是同一世界。

AFTER_DAMAGE可带 `damage.type`（当前注册DamageType标识，未知为unregistered）、
requested_amount、returned（未正常返回为null）。没有该字段的采样变化不猜来源。
returned=true不等于掉血，可能只有吸收变化；returned=false也不覆盖实际观测到的变化。
不记录攻击者文本、实体NBT、玩家存档全文、模型参数、令牌、API配置或机器路径。
诊断自身的RuntimeException只给每身体一次固定警告，不替换动作结果或原伤害异常。

**边界**：这是生命周期/调用边界采样，不拦截所有setHealth、网络同步或第三方直接写值。
同一采样间隔内先减后恢复可能没有差异；构造完成前的变化未观测。
原hurtServer或其他模组中的嵌套写值也不能仅凭来源字段做独占伤害归因。
没有实际世界执行证据前，编译及替身通过不能称该现场原因已找到或已修复。

## 4. 集中测试时怎么留证

使用最终包及 `templates/RG6-OBSERVATION-FEEDBACK.md`，顺带记录已有补测的真实状态。
不强制重跑已认可T04/T18，不要求现在进游戏，不为了填表刷模型或制造伤害。

生命：先保留本次身体从CREATED到READY的诊断，再用G“查看状态”按钮取得直接回执；
这个观察项可以用按钮，不用模型自述替代血量。现成移动测试前后各读一次状态，
记录首个变化的previous/current和damage（若有）。已经加载为19时照实记录，
不补血、重召或编辑.dat掩盖它，也不把不再下降算成根因修复。
未复现就记未复现；空日志/诊断警告或只有模型汇报均不足以定位首次变化。

身份：仅在已有退出重进/B01重连，或维护者另行选择复现错名时取样。
协作者同时记录实际游戏伙伴、REST status的session_id/companion、SSE session/id/task、
宿主收到的名称与最终展示，首次新桥尚未同步时companion=""是合法未确认。
同会话名称从空变成实际名字时也必须更新，不能仅在session变化时刷新名称。
没有真实status/载荷关联时只记“待对齐”，不凭口头名字定责任。
协作者采集时隐藏Authorization、token和完整带鉴权URL，不将配置文件带入反馈。

只有前后直接状态和新诊断定位相符，才确定变化发生在哪段路径；只有各层身份完整对齐，
才区分本体同步、连接器缓存/转达或宿主展示责任。两项分别挂账，不自动关闭B01或其他测试债务。
