## 执行策略

| 项目 | 当前策略 |
| --- | --- |
| 模型轮数、长期阶段数 | 默认不限；宿主显式正步帽、max_runs正数仍有效 |
| 重复调用、空搜索、拒绝假完成 | 保留提示、真实结果和目标核验，不按次数终止 |
| WorkFailureMemory | 仅诊断；128条滚动记忆，不拒发工具，也不以记满终止 |
| run_program | 默认timeout_seconds/max_calls为0，不限总时长与调用数 |
| 嵌套原子调用 | 仅显式正max_calls时预扣并执行相同上限 |
| Lua计算 | 去掉总指令累计帽；保留两次API之间25000指令及内存/输出/深度保护 |
| gather/explore | 默认无总时间、总挖掘和移动次数额度；显式正额度仍有效 |
| gather局部工作 | 去掉三次未入包停止；按当前实际候选、工具、拾取与范围反馈结算 |
| 地下勘探 | 累计挖掘数仅诊断；每路段仍限制编辑量并核耐久、补给、返程证据 |
| 工地 | 去掉16轮/128改动和重复事实终止；累计数及128条滚动指纹仅诊断 |
| mc.build | max_rounds默认0不限，可显式正数限制；仍须完整新鲜全目标验收 |
| workflow | 去掉默认180秒及累计128件额度；仍为明确的1–12步载荷，逐步真实终态 |
| 导航 | 每次8000节点/32768记录/400ms，默认无累计两次重规划门 |

0或省略代表不限的参数以各工具Schema为准；explore_steps=0仍表示关闭换区，
max_steps/max_blocks用省略代表不限。内部Integer.MAX_VALUE为无限探索哨兵，
对人类反馈显示“不限”，实际次数仍累计。保存的显式有限探索/阶段参数继续沿用，
不据恢复任务自动加额度。旧导航快照缺per_search字段时迁移为逐次资源保护，
新快照显式有限总账户仍按其设置恢复。旧停止/在途/未知检查点不自动复活。

真实失败仍结束相应原子动作或组合，把结果交给外层模型选择；这不禁止后续新调用。
mc.call遇失败停止程序，mc.try_call只允许读取既有局部失败类别，后续动作前仍须
status details=true检查完整身体。权限、未知状态、取消、缺工具/材料等不吞掉。
最终目标须真实现场满足，模型反复说“完成”不会伪造成功。

本轮保留单次动作期限、攻击1–10次/20秒、真实攻击距离、单路段挖放、
身体控制互斥、网络回执期限、上下文/输入/输出及来源存储保护。
例如工地临时来源16条、实际路线256条、地下返程4096点和建筑来源事件存储仍有界；
这些保护不能以淘汰尚需的来源或返程证据来放开。没有宣称所有限制已删除。

## 导航及攻击

NavigationSnapshot在世界线程复制已加载区段调色板，冻结身体尺寸、数值世界边界、
固定任务范围和起点。后台对象不保留活世界/身体引用，不加载未知区块。
NavigationSearch以两个低优先级守护线程搜索，队列32；合作取消并移除排队项，
结果完成后才移交世界线程。取消、终态、休眠和身体中断不采用迟到结果。

普通位置与显式近战接近先尝试无编辑快照路线；执行前用活世界重建并核验路线、
起点与每条实际移动边。等待期间身体离开原起点则重新规划。
工作到达、编辑成本、工地及自定义约束仍走既有主线程300节点/6ms切片；
可编辑普通路线的干走搜索失败或线程队列繁忙时也可回退。
这不是完整编辑世界后台化，尚无走当前段时预搜下一段。

到站单节点改为复核自身支撑和净空，DigAStar在已满足目标时保留分数脚高；
同高无编辑、无跳跃且不反向的中间转弯节点可连续通过，下一边必须新鲜可行。
终点、坡地、反向和编辑仍要求站稳，不承诺自然地形全程无停顿。

EntityApproach保留仍有效路线及在途搜索，进入攻击范围只释放输入，离开后续用。
目标明显移动且路线终点无用才更新路线；不因边界进出重花两次重规划额度。
显式approach固定范围扩为起点64格，仍绑定原目标UUID和真实原版攻击距离；
中立目标批准摘要包含新范围。被动自保保持原近场范围，不自动换目标。

日志/终态与路线观察新增search_mode；BACKGROUND_SNAPSHOT的worker_search_ms
与主线程PathTiming.SEARCH分列，后者仍包括采样、派发、收取结果等主线程开销。
需要编辑或工作到达的主线程回退仍可能接近原400ms搜索耗时。
