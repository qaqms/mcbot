# mcbot 0.1.0 测试版

用于新建测试世界的首轮实机验收。本版本已完成合并后的离线验证，真实游戏动作和连接器联合验收仍待测试反馈。GitHub 标为 Pre-release，模组版本保持 **0.1.0**。

## 下载与安装

- **首次测试推荐**：下载 `mcbot-0.1.0-test-kit.zip`，解压后先看 `START-HERE.txt`，再打开 `dist/game-testing.html`。
- **只更新模组**：下载 `mcbot-0.1.0.jar`，关闭游戏后放入对应实例的 `mods`，移走旧版 mcbot。
- **单独填写反馈**：下载 `game-testing.html`，用浏览器打开，每轮结束导出反馈 JSON 和日志交回维护者。
- `SHA256SUMS.txt` 提供 JAR、测试压缩包及 HTML 的校验值。下载后可核对，避免同名旧包混用。

运行环境：**Minecraft 1.21.11 / Fabric Loader 0.19.5 / Fabric API 0.141.6+1.21.11 / Java 21**。
Fabric API 需另行安装，不包含在本测试压缩包中。联机服务器安装同一个 JAR，客户端和服务端一起更新。
不需要编译或启动开发服务器；首次使用创造、超平坦、允许作弊的新测试世界。

发布页：<https://github.com/qaqms/mcbot/releases/tag/v0.1.0>。

## 本次内容

- 完整背包读取、主手切换、普通配方合成，以及熔炉、高炉、烟熏炉操作。
- 物品存取、拾取和挖掘掉落按真实数量记账；单格挖放使用原版动作入口。
- 统一任务调度、只读权限、具体路线确认和取消收尾。
- 有界单目标近战，每轮最新身体状态、资源搜索和容器明细。
- 有界 workflow 组合步骤、失败停止和取消后保留真实已完成结果。
- 新手必测手册：18 项本体测试，另有 1 项连接器准备好后的联合测试，支持本地填写及导出反馈。
