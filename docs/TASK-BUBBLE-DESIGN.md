# Bot头顶任务气泡设计（2026-10-15）

范围：维护者已批准头顶方案，原生实现已接入；离线验证及候选包以STATUS顶部为准。
设计原型为 `../dist/task-bubble-preview.html`，直接打开即可，无网络依赖。
原型使用示例数据和原创像素场景，场景不是Minecraft截图；设置仅存浏览器预览偏好。

## 使用目标

玩家在正常游戏中能知道同伴正在做什么、是否在等待自己、最后是否成功，
不必反复打开G面板。气泡是可选的任务显示入口，详细对话和授权仍在G面板。
维护者已明确气泡必须在Bot头顶，跟随实体的世界位置；此前固定屏幕左下角的理解有误，
此稿已更正。Bot不在视野或被墙遮挡时隐藏，不转为屏幕角落提示。

## 视觉方案

- 锚定Bot插值后包围盒顶部，额外留出原名字标签和约0.35至0.5格的气泡间隙，
  文本面向玩家相机，尾巴居中指向Bot。行走、跳跃、转头和相机移动时均跟随，
  不额外叠加上下漂浮动画。
- 近处紧凑可读，远处随距离缩小并淡出，建议24格外不显示；具体阈值待原生体验定值。
  头顶锚点在视锥外、相机后方或被实体前方的不透明地形遮挡时隐藏；
  屏幕边缘按实际投影裁剪，不把气泡吸附在屏幕边缘。最初只向拥有者展示自己Bot的任务。
  HTML模拟二维头顶投影、位置滑杆、近中远距离及遮挡/画面外选项，不是实际世界渲染。
- 单气泡，细描边、8像素内圆角、小像素尾巴、低对比阴影。
  头顶版移除重复头像和点击按钮，直接由下方Bot及名字标签表达归属；场景人物为原创占位图。
  不叠多个气泡，不滚动播报每次工具回执。
- 顶部同伴名和状态；中部最醒目的是当前动作；底部次要展示原任务名。
  当前动作最多两行，任务名一行省略；完整内容由G面板承载。
- 执行用清淡青绿，待回答/确认用琥珀，受阻/失败用柔和红，取消用中性灰。
  同时保留文字和符号，不依靠颜色辨别。深色主题使用实底保持可读性，
  原型的地下场景同时演示深色；正式版跟随已有主题设置，不因高度猜测主题。
- 趣味来自小气泡尾巴和三点轻呼吸；气泡与身体同步移动，
  不闪烁、打字、播放提示音或频繁改变整体尺寸；支持关闭系统动画偏好。

## 状态与信息

| 状态 | 主文案示例 | 行为 |
|---|---|---|
| 本地执行 | 正在挖掘 / 正在查找资源 / 正在移动 | 展示实际执行阶段，动作变化时更新 |
| 模型等待 | 等待下一步；等待模型响应 | 轻微三点动画，不展示模型内部推理 |
| 整理上下文 | 正在整理上下文 | 与模型响应等待分别表达 |
| 地下勘探/返程 | 正在地下勘探 / 正在沿路标返回 | 需新增结构化活动快照；不能从现有合并字符串猜测 |
| 等待回答 | 想问你一下 + 问题短预览 | 显示实际剩余时间，回答仍从G面板进入 |
| 等待授权 | 这一步需要确认 | 气泡只提醒，完整清单与批准仍在原确认框 |
| 已完成 | 任务完成了 | 仅真实整任务成功终态；约6秒后收起 |
| 受阻/失败 | 暂时走不通 / 任务未完成 | 简短实际原因，约10秒后收起，完整原因保留在G面板 |
| 已取消 | 任务已取消 | 约4秒后收起，不据此声称服务端身体已确认停手 |
| 空闲 | 无 | 不常驻空白气泡 |

有新任务即替换旧终态；长期目标中间阶段保持执行态，不弹“任务完成”。
取消/替换/退出世界按任务身份清理旧显示，旧回调不能改新任务气泡。
排队任务不冒充正在执行；问答优先于动作提示。
打开任意界面或F1隐藏GUI时隐藏，继承现有HUD语义。
完成提示在界面打开时也计算期限，关闭面板后不重放已过期的终态。
原型为方便比较固定展示各终态，不自动倒计时；正式接线时实现上述真实期限。

数量只来自新鲜背包核验，并明确标为“本段圆石 · 已入包 12/24”等材料子目标。
这条细进度线只表达此物品的数量，不表达制作铁镐或整个长期任务的完成率。
没有可验证数量时省略数量区和进度线；未知不用0代替。
示例措辞是状态文案，不向模型增加固定任务流程。

## 设置与交互

沿用G面板 → 设置 → 通用中的show_hud，把“游戏内状态提示”改名“Bot头顶任务气泡”。
默认沿用现有true，已有false保持关闭，不新增两个功能重叠的总开关。
原生实现已用头顶显示替换原任务状态条，不同时显示相同内容。
和原设置一致，保存成功后生效；写盘失败不改变运行偏好。
显示偏好变更不取消任务、不重建模型、不改变权限；关闭后问答和任务仍存在于G面板。

普通游戏鼠标锁定时，气泡只展示、不抢焦点，原G键仍能查看详情。
气泡自身没有按钮，也不截获攻击/交互输入。原生第一版以G进入面板，
不为点气泡额外解锁鼠标或新增光标模式。
原型“示例详情”按钮放在场景外，仅用来比较完整示例内容，不是头顶气泡的一部分；
详情框没有执行批准、取消或发出新任务的能力。

## 原生接线

- CompanionTaskBubble使用Fabric世界提取和绘制事件，替换CompanionHud及HUD注册。
  提取时读取当前世界中由UUID精确绑定的Bot，取插值位置、包围盒高度加0.72格作为尾尖；
  世界渲染状态只携带布局、坐标和配色等不可变帧数据，不保留实体或runner引用。
  绘制阶段使用相机相对坐标、相机旋转、正常深度测试文字和光照顶点背景。
- 原生固定184×88世界像素，3像素阶梯圆角和6像素居中尾巴；主题跟随已有dark偏好。
  动作和任务标题各一行省略，问题/实际原因最多两行。数量区与问题区互不挤占。
  第一版采用静态呈现，不叠加呼吸、打字或上下浮动动画；趣味由尾巴及轻配色表达。
  原型的三点呼吸保留为预览效果，未增加独立动画偏好。
- 24格截断、20至24格淡出；近于4格时限制放大，投影自然随距离缩小。
  锚点必须在相机前和视锥内，再以VISUAL方块射线核对Bot眼睛未被挡；
  背景和文字仍按世界深度裁剪。透明方块/特殊形状的实际观感尚待游戏补测。
  自己世界、自己的Bot实体、show_hud、无界面/F1等守卫共同准入；无屏幕角落回退。
- 内部companion_state/summon_result/dismiss_result增加companion_uuid，仅回给请求的主人。
  缺失/非法UUID不按名字猜测；同名换UUID、遣散/换世界会清理旧显示与身体读数代际。
  因此联机客户端/服务端应同步更新；旧服务端缺UUID时保留面板，气泡不绑定。
  外部任务桥v1.0及宿主/连接器均未改。
- TaskBubbleState按task_id、工具seq保存真正已发出的活动；受理不清除，
  真终态/超时/组合取消才结算，面板只读检查不覆盖任务动作。
  问答优先于整理/勘探/实际原子动作/模型等待，地下勘探与返程由明确mode区分。
  不解析日志、工具feedback或模型回复来推测当前阶段，也不新增规划层或模型请求。
- ItemGoal.Progress为只读数量快照，采集期间优先显示本段目标，未知时省略。
  净增和总量分列，配方替代来源明确为合计件数，不把挖掘/地上掉落算入包。
  材料段结束后回到最终目标；完成时保留最终核对数量，普通文字任务显示“任务已结束”。
  长期阶段检查点不结束显示；完成/失败/取消分别保留6/10/4秒，隐去时期限继续推进。
  新任务替换旧终态；排队任务取消、旧回执不能覆盖当前任务，重载/退出清空。
- show_hud保持原配置默认及保存语义，只改设置名称。关闭只影响显示，
  不取消任务/问题、不重建大脑、不改变权限；写盘失败不应用偏好。

后续原生验收覆盖头顶对齐、走跳插值、视角旋转、距离缩放/淡出、墙体遮挡、
视锥外不显示、同名实体不误绑、GUI缩放/小窗口、长中文名和任务名、待答超时、终态期限、
长期阶段不误报完成、显示开关保存失败与取消隔离、F1/菜单隐藏及退出重进。
浏览器布局验证仅证明HTML原型；原生回归使用实际runner/数量/提交/矩阵和受控边界，
未启动游戏、真实模型或自动安装，不能作为GPU画面与身体走跳实测。
